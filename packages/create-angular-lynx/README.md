# create-angular-lynx

Scaffold an [angular-lynx](https://github.com/shabeliuk/ng-lynx) app —
standalone, zoneless Angular rendered as native UI on the
[Lynx](https://lynxjs.org/) engine.

```bash
npm create angular-lynx@latest my-app
npm create angular-lynx@latest my-app -- --template router
```

Templates: `minimal` (default), `router` (lazy route included), `forms`
(`[(ngModel)]` + headless controls).
